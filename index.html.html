Timing

Every line lands
exactly where it started.

Not translated. Fitted.

A translation is not a dub.

It has to land in the same moment as the original. Against the picture. Against the pause. Against the breath the speaker took.

Hindi runs long.

The same sentence needs more syllables. Most tools squeeze the audio until it fits. That squeeze is what machine dubbing sounds like.

So we rewrite instead.

A shorter way to say the same thing. A slightly quicker delivery. Only then, a touch of timing — inside a limit that stays clean.

And when it still won’t fit, it waits.

Held for a person rather than forced through. A system that always returns something always returns some things wrong.
