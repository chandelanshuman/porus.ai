PORUS.AI LOGO FILES  (built from "Porus.ai identity" sheet, Rev 1 · Sep 2026)

All artwork is outlined vector — no live text. Built to the sheet's construction:
  Brahmi: Noto Sans Brahmi, exact string U+11027 U+11044 U+1102D U+1103C U+11032 (pō·ru·sa), 0.05em tracking
  Latin:  IBM Plex Mono Medium (500), 0.47 S, 0.22em tracking, uppercase
  Tick:   0.028 S wide × 0.36 S tall, 0.42 S gap each side
  Clear space of 0.5 S is baked into every SVG's viewBox.

svg/   scalable masters (use these on web; transparent unless the name says on-white / on-black)
png/   4x raster exports for slides and docs
preview/  the transparent white/gold files shown on a dark background so you can see them
